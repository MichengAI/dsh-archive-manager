## 機能概要

一時的に使わない会話を整理して保管し、必要な時にいつでも復元。日常のタスクリストを常に整理された状態に保ちます。

- **二重ビューとプライマリサイドバーエントリ**：ホストのメインサイドバーに常駐する専用ナビゲーションアイコンから、**960px 中央寄せのワークスペースビュー** を展開。「アーカイブ済み」と「未アーカイブ」の大型パネルを快適に操作でき、狭いダイアログのスクロール制約から解放されます。
- **フルライフサイクル管理**：個別セッションのアーカイブ、ワークスペース全体のワンクリックアーカイブ、プロジェクト横断の一括アーカイブ、個別・一括の復元と直接オープンを完全サポート。
- **サイドバー全行右クリック操作**：サイドバーのワークスペース行やセッション行の任意の余白を右クリックして専用操作メニューを呼び出し可能。未分類や未保存の行ではシステム標準の右クリックが安全に機能し、誤操作を防ぎます。
- **ブレなし星標配置と状態ドットの完全共存 (#90, #92)**：お気に入り星標を標準の 16×16px に揃え、ホストの先頭スロットに絶対配置で重ね合わせることでタイトルの横ブレを解消。セッション実行中や承認待ちの際も、ホストの状態ドットを完全に表示したまま星標が右下 10px のバッジに自動縮退し、カスタムスキン環境でも美しく調和します。
- **ワークスペースクイック操作メニュー**：サイドバーのワークスペースメニューから「フォルダパスをコピー」「フォルダを開く」（Windows Explorer または macOS Finder を直接起動）、「セッションをアーカイブ」を素早く実行。
- **ワークスペース間のセッション移動**：ホバーで開くカスケードサブメニューからセッションを別のワークスペースへ移動可能。実行中プロセスの静穏化、アトミックなファイル書き換え、投影キャッシュの即時ウォームアップ、NTFS コロン安全性を備えています。
- **一体型アコーディオンカードと 40px 超コンパクト行**：Skills Manager と同等の統合型ドロワーカード（38px ヘッダー）でプロジェクトグループを統一。セッション行の高さを 40px に凝縮し、情報密度を倍増させました。
- **ホストネイティブなダークモードチェックボックス**：ホストの標準 Checkbox 仕様と `accent-color` に準拠し、ダーク背景とブランドブルーのチェック状態に完璧に調和。
- **背面透け防止モーダルと多言語アクセシビリティ**：大型プレビューダイアログを `body` 直下（`portalToBody`）にマウントし、遮光背景とすりガラスぼかしで背面の文字透けを防止。全言語対応の閉じるボタンアクセシビリティラベル（`common.close`）を提供。
- **標準化されたセクション ID と共存保護 (#91)**：設定ページの登録 ID をチーム統一仕様の `archive-manager` に改定し、フェイルソフトなランタイム保護を導入。サードパーティ製アーカイブプラグインと安全に共存可能。
- **洗練された単一行適応型ツールバー**：ホスト標準の `Input` 原語、公式検索アイコン、緑色フォーカス枠を採用し、残りの幅を適応的に拡張。検索ボックス、表示・ソートメニュー、プロジェクト絞り込み、日付範囲を一行にスマートに配置。
- **全文検索と Codex 風複合メニュー**：タイトルと会話本文（ユーザーおよびアシスタントのメッセージ）の両方を網羅する検索。セッション絞り込み（すべて／お気に入りのみ）と並び替えをチェックマーク付きの Codex 風メニューに統合。
- **軽量 DateRange カプセルとカレンダーポップオーバー**：ネイティブ日付入力を完全に刷新し、ダークモードの反転やフォーカス喪失を解決 (#74)。単一行カプセルで選択範囲を表示し、クリアボタン、クイックプリセット、全 8 言語の曜日・月表示、WAI-ARIA キーボード操作（矢印、Home/End、PageUp/Down、月跨ぎ補正）を完備。
- **アイドルセッションの自動整理**：経過日数を指定して長期間活動のないセッションを検出。実行中タスク、対話プロンプト、お気に入りを自動保護し、即時取り消し（Undo）にも対応。
- **完全物理削除**：不要なトランスクリプト、キャッシュ行、インデックスを物理的に完全消去。失敗した項目は個別に再試行可能。
- **孤立サブエージェントの検出と解放**：親セッションが外部から物理削除されて残された孤立サブエージェントを自動検出し、ディスク使用量を表示してワンクリックで物理解放。
- **企業向け Cordis 宿主設定ロックとリバースプロキシ対応**：Cordis 設定ファイル（bundle patch）によるセキュリティ完全ロックをサポート。プレフィックスを除去するリバースプロキシ配下でも `document.baseURI` により自動的にエンドポイントを解決。

## 手動リストキャッシュ再構築 (#88)

アーカイブマネージャーを開くと、登録済みワークスペース、未分類リスト、アーカイブ内の通常のコールドセッションのヘッダーと公式キャッシュ投影のみをチェックし、IM チャンネルセッション（`im:`）は除外されます。キャッシュが欠落または非互換の場合、あるいはタイトル投影が利用できない場合にのみ修復カードが表示されます。クリックすると読み取り専用ハンドルを介してログを 1 つずつ読み取り、公式 `coldSnapshot` で投影を再構築して `session_projcache` に保存します。

古いプラグイン領域のスキャン、JSON コピー、セッション/エージェントの起動、モデルの呼び出しは一切行わず、アーカイブやスケジュールも変更しません。実行中のセッションはスキップされ、失敗した項目は個別に再試行できます。完了後は公式セッションリストが更新され、候補が再確認されます。

## 孤立サブエージェントのクリーンアップ

親セッションが外部ツールやホストによって削除された場合、残された孤立サブエージェントがディスク上に残ることがあります。アーカイブマネージャーの「整理」パネルでこれらの孤立セッションを検出し、ディスク占有容量を計算してワンクリックで物理削除できます。

## 検索とプレビュー

- 「アーカイブ済み」と「未アーカイブ」の両タブで、タイトル/本文検索、プロジェクト絞り込み、お気に入り、更新日フィルター、作成日ソートを共有。どちらのタブからでもスターの付け外しが可能です。
- 検索はタイトルだけでなく会話本文（ユーザーとアシスタントのメッセージ）も自動的に対象とします。日付フィルターはユーザー現地の終日を含み、プロジェクトやお気に入りと組み合わせて絞り込めます。
- 一致した箇所にはスニペットとハイライトが表示されます。「アーカイブ済み」ではスニペットまたは「詳細 → クイックプレビュー」をクリックして復元せずに文脈を確認でき、「未アーカイブ」ではクリックして会話を直接開きます。
- プレビューは Markdown の表、引用、コードブロックをロールラベル付きでレンダリングします。ハイライトを確認したい場合は原文表示に切り替え可能です。最新の最大 8 件のメッセージ、または最初の一致箇所の前後を表示します。1 メッセージあたり最大 2,000 UTF-16 コードユニットで安全に切り詰めます。
- 検索クエリは最大 200 文字、1 バッチあたり最大 20 セッションを順次読み取ります。ツール、添付ファイル、推論、システムメッセージ、プラグイン挿入データは除外されます。
- 永続的な全文インデックスは保持しないため、長大なセッションが多い場合はプロジェクトや日付で絞り込んでから検索してください。

## インストール手順

DeepSeek Harness 環境が必要です。以下の例では `web` プロファイルを使用しています。環境に合わせて調整してください。

### エージェントに依頼してインストール
お使いのコンピュータでターミナルコマンドを実行できるエージェントに次のプロンプトを送信してください：

```text
公式 npm レジストリから最新の @michengai/dsh-archive-manager を DSH の web プロファイルにインストールし、アクティベーションを確認してリロード手順を説明してください。
```

### 手動でインストール

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
dsh plugin --profile web add @michengai/dsh-archive-manager@latest --registry=https://registry.npmjs.org/
```

インストール後、DSH Web を再起動し、ブラウザでページを更新（または `Ctrl+Shift+R` でハードリフレッシュ）してください。「設定 → アーカイブセッション」を開いて利用を開始します。更新時は同じインストールコマンドを再実行するだけです。

- **ホスト対応範囲**：DeepSeek Harness `0.2.x` 全シリーズ（`>=0.2.0-rc.1 <0.3.0-0`）。全 RC 版（`0.2.0-rc.1`, `0.2.0-rc.2`, `0.2.1-rc.1`〜`0.2.1-rc.5`, `0.2.2-rc.1`）で検証済みです。
- `0.2.0-rc.1` 未満の旧バージョンホストはサポート終了しました。`0.1.x` をご利用の場合はプラグイン `1.0.20` をご利用ください。
- **リバースプロキシ対応**：`/app/dsh/` などのサブパス配下に配置されたリバースプロキシ構成にも完全対応。API エンドポイントはページのベース URI（`document.baseURI`）に基づいて動的に解決されます。

## プラグイン設定

DSH 標準のプラグイン設定に準拠しています：
> **サイドバー → プラグイン → `Archive Manager` をクリック**（ホストの `plugins.bundle.config` スロット）

### 1. エントリ表示位置 (`entryLocation`)
- **すべての場所 (`both`)**：左サイドバーにアイコンを表示し、「設定 → アーカイブセッション」の項目も維持します。
- **サイドバーのみ (`sidebar`)**：左サイドバーにアイコンを表示し、設定ページの項目を登録解除して設定画面をスッキリさせます。
- **設定のみ (`settings`)**（デフォルト）：左サイドバーを最小限に保ち、「設定 → アーカイブセッション」からアクセスします。

### 2. オンライン更新ポリシー (`onlineUpdate` / `updater`)
- **設定方法**：企業のセキュリティコンプライアンス環境などでは、Cordis 設定ファイル（bundle patch）から更新を無効化できます：
  ```yaml
  updater: false # または onlineUpdate: false
  ```
  設定すると起動時にアップデータが無効化され、未検証の外部バージョンがインストールされるのを防ぎます。

## よくある質問

### インストールしたのにエントリが表示されません
DSH Web を再起動し、ブラウザをスーパーリロード（`Ctrl+Shift+R`）してください。使用中のプロファイルに正しくインストールされたかご確認ください。

### アーカイブと削除の違いは何ですか？
アーカイブは後から復元できるように一時的に会話を片付ける操作です。**完全削除は取り消すことができず**、セッションログや添付ファイルも物理的に削除されます。削除時は確認ダイアログが表示されます。

### Codex UI と併用できますか？
はい。[Codex UI](https://github.com/MichengAI/dsh-codex-ui) の外観とサイドバー操作を維持したまま、**設定 → アーカイブセッション** からスムーズに利用できます。

### 他のアーカイブプラグインとの共存について
本プラグインは設定セクション ID `archive-manager` を使用して登録されます。他のセッションアーカイブプラグインがインストールされていても独立して共存・動作します。

## 検索 API の互換性（インテグレーター向け）

正式な API は `workspaceRegistry.searchSessionContent({ sessionIds, query })` であり、アーカイブ済みと未アーカイブの両方のセッションを網羅します。1〜20 件のセッション ID と 1〜200 文字の空でないクエリを指定します。重複する ID は自動的に除外されます。戻り値の形式は `{ items: [{ sessionId, seq, snippet }], failures: [{ sessionId, message }] }` です。個別の読み取り失敗は `failures` に記録され、不正な入力はリクエスト自体が拒否されます。

`searchArchivedContent` は従来のアーカイブ専用レガシーエントリとして引き続き利用可能です。いずれも既存のホスト Typert 接続と認証境界を使用し、追加の HTTP エンドポイントや認証設定は不要です。

## 更新

アクティブな DSH プロファイルで上記のインストールコマンドを再実行するだけで更新が完了します。企業のセキュリティポリシーなどで更新を制限したい環境では、Cordis 設定を介してアップデータを無効化できます。
