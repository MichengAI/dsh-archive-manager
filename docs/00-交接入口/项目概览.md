# 项目概览

> 更新时间：2026-08-17 12:00（Asia/Shanghai）

## 项目定位

`@michengai/dsh-archive-manager` 是一个可 npm 安装的 DSH Web 插件，为 DeepSeek Harness（DSH）提供已归档会话的管理能力：归档 / 取消归档、永久删除（含 SUBAGENT 子会话级联）、归档设置页（搜索、按项目筛选、全部删除）。

## 运行时结构（三个模块，经 package.json 子路径导出）

| 模块 | 职责 | 替换的默认服务行（cordis.patch.yml） |
|------|------|--------------------------------------|
| `lib/workspace.js` | 宿主工作区服务：归档标记、删除链路、级联、墓碑 | `workspace`（→ `workspace-archive-manager`） |
| `lib/projcache.js` | 宿主投影缓存服务：墓碑守护的 `write` / `putSoft` 与 `whenIdle` | `session-projection-cache`（→ `session-projection-cache-archive-manager`） |
| `lib/client.js` | 浏览器端 bundle：侧栏浏览器、归档卡片样式、设置页 | `ui-workspace`（→ `ui-workspace-archive-manager`） |
| `lib/tombstone.js` | 内部共享工具：`trackTombstone` 墓碑登记与 FIFO 淘汰 | 无（被 workspace / projcache 内部引用） |

## 关键设计

- **删除链路顺序即语义**：flush → detach → `whenIdle`（等投影写后落盘）→ 清归档标记 / 工作区记账 → 删投影缓存行 → 级联 SUBAGENT 子会话 → 清 spill → 物理删除转录目录 → 遗忘内存索引并打墓碑。可失败清理全部先于不可逆删除。
- **墓碑双用途**：一是阻止 stale `persistence.list()` 把已删 id 救活；二是记录被删生命周期的日志身份（createdAt/cwd），`sessionKnown` 的冷复用探针据此放行其他进程以同 id 重建的新会话。
- **投影缓存守护**：`write()` 与 `putSoft()`（`coldSnapshot` 冷读写回）两条落盘路径都受墓碑拦截并纳入 `whenIdle` 跟踪，删除不会留下复活行。
- **设置页分组身份**：分组 key / 筛选 value 用 `workspaceId`（上游允许工作区同名），选中分组消失时筛选自动回退“所有项目”。

## 测试与构建

- 测试：`pnpm test`（`node --test test/*.test.mjs`，共 49 项：宿主行为 + 纯函数 + 源码文本断言）
