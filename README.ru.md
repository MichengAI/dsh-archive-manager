> DSH Archive Manager — это поддерживаемый сообществом плагин для DeepSeek Harness (DSH), а не официальный продукт DeepSeek AI.

## Что умеет плагин

Убирайте неактивные беседы с глаз долой и находите их, когда они снова понадобятся, держа список повседневных задач в порядке.

- **Архивировать беседы**: убрать один чат или все незаархивированные чаты рабочей области.
- **Находить прошлую работу**: искать по названиям и содержимому, комбинировать фильтры по проекту/избранному/дате, сортировать по времени, названию или числу ходов.
- **Восстанавливать задачи**: восстановить один чат, выбранные чаты или группу проекта; выбрать все отфильтрованные результаты для массовых действий.
- **Очищать записи**: безвозвратно удалять ненужные архивы после подтверждения, отслеживать прогресс пакетной обработки и повторять оставшиеся элементы.
- **Упорядочивать важные чаты**: сохранять избранное и предпросматривать очистку неактивных, защищая избранное и активную работу.
- **Проверять и устранять неполадки**: предпросматривать без восстановления, копировать ID/пути, диагностировать ошибки и чинить поддерживаемые устаревшие журналы.

> В этом README описан выпуск 1.0.0. Полный список возможностей и границы обновления — в [истории изменений](CHANGELOG.md).

## Диагностика и ремонт сессий

Страница архива собирает ошибки чтения, включая ID архива без сводок. Разверните **Диагностика и ремонт**, выберите **Диагностировать сессию**, затем **Подтвердить ремонт** — только когда это допустимо. Ремонт преобразует поддерживаемые устаревшие источники, включая автоматизацию и ранние подсказки, сохраняя исходный журнал и текст беседы. Сессии должны быть архивированы и закрыты во всех процессах DSH. Отсутствующие файлы, отказы прав и неподдерживаемые повреждения сообщаются; сообщения никогда не обрезаются и не удаляются ради принудительного восстановления. Допустимость проверяется по артефактам и формату хоста, а не только по тексту ошибки.

## Поиск и предпросмотр

- **Архив** и **Незаархивированные** используют общий поиск по названию/содержимому, фильтры проекта, избранного и даты обновления, а также сортировку по времени создания. Ставьте или снимайте избранное на любой вкладке.
- Поиск по умолчанию автоматически охватывает как названия, так и текст истории сообщений (включая пользователя и ассистента). Фильтры дат включают весь локальный конечный день и комбинируются с проектом и избранным.
- Совпадения показывают фрагменты и подсветку. На вкладке **Архив** щёлкните фрагмент или **Дополнительно → Быстрый предпросмотр**, чтобы изучить контекст без восстановления. На вкладке **Незаархивированные** фрагмент открывает полную беседу.
- Предпросмотр рендерит Markdown-таблицы, цитаты и блоки кода с подписями ролей; переключитесь на исходный текст для подсветки. Показывается до восьми последних сообщений либо контекст вокруг первого совпадения. Каждое сообщение ограничено 2 000 кодовых единиц UTF-16 без разрыва Unicode-символов.
- Поиск принимает до 200 символов запроса и читает пакетами максимум по 20 сессий последовательно внутри каждого пакета. Инструменты, вложения, рассуждения, системные сообщения и плагинные вставки исключаются. Ошибки чтения остаются видимыми и их можно повторить. Сохранённый текст — это не текущий контекст модели.
- Постоянного полнотекстового индекса нет. Большие или длинные беседы могут обрабатываться медленно; сначала сузьте по проекту, датам или избранному. Никаких гарантий по числу сессий или задержке не установлено. Смена фильтров останавливает последующие пакеты и устаревшие результаты, но не может прервать уже читаемый пакет.

## Число ходов и местоположение

- Обе вкладки показывают число отправок от пользователя, включая отправки изображений; ответы ассистента, вызовы инструментов и вставленные сообщения не считаются ходами.
- Сортируйте по наибольшему или наименьшему числу ходов; неизвестное число остаётся в конце. Ошибки деталей можно повторить.
- **Дополнительно** даёт раздельное копирование ID/пути. Официальное хранилище JSONL возвращает каталог сессии; другие бэкенды используют корректный путь, предоставленный хостом. Операции с буфером обмена требуют разрешения браузера и HTTPS или localhost; сбои сообщаются.
- Детали читаются пакетами до 20, без активации или восстановления сессий. Счётчики включают унаследованные сообщения пользователя, не имеют постоянного индекса и могут занимать время для длинных журналов.

## Предварительные требования

- Рабочая установка [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web с доступным `dsh` в терминале.
- Поддерживаемые версии DSH: `0.2.0-rc.1`, `0.2.0-rc.2`, `0.2.1-rc.1`, `0.2.1-rc.2` и `0.2.1-rc.3`. Промежуточные выпуски `0.2.1-alpha.*` и более ранние хосты отклоняются проверкой версии, и плагин не запускается. Существующие архивы и избранное сохраняются. Для `0.1.x` установите `1.0.20`.
- Node.js версии `^22.19.0 || >=24.0.0`. Для установки из исходников также требуется pnpm.

## Установка

В примерах используется профиль `web`. Замените его на тот профиль, который вы действительно используете.

### Попросите агента установить

Отправьте этот запрос агенту, умеющему выполнять команды в вашем терминале:

```text
Установи последнюю версию @michengai/dsh-archive-manager в мой локальный профиль DSH web, используя официальный npm-реестр. После установки проверь конфигурацию плагина, затем объясни, как перезагрузить DSH и открыть управление архивированными сессиями.
```

### Установка вручную

Выполните в PowerShell:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

dsh plugin --profile web add @michengai/dsh-archive-manager@latest --registry=https://registry.npmjs.org/
```

Перезапустите DSH Web, затем жёстко обновите браузер (`Ctrl+Shift+R`). Откройте **Настройки → Архив сессий**, чтобы начать работу.

## Использование

| Цель | Действие |
| --- | --- |
| Архивировать один чат | Откройте меню сессии на боковой панели и выберите **Заархивировать сессию** |
| Архивировать рабочую область | Откройте меню рабочей области и выберите **Заархивировать все чаты** |
| Найти архив | Откройте **Настройки → Архив сессий**, затем выберите поиск по названию/содержимому или фильтруйте по проекту, избранному и датам |
| Изменить порядок | Сортируйте по времени обновления, времени создания, названию или числу ходов (больше/меньше) |
| Восстановить один чат | Щёлкните значок восстановления или выберите **Дополнительно → Восстановить и открыть** |
| Архивировать проект или несгруппированные чаты | На вкладке **Незаархивированные** откройте меню **…** группы и подтвердите архивирование всех чатов этой группы независимо от фильтров поиска |
| Избранное для чата | Щёлкните звезду справа; используйте выпадающий список избранного для фильтрации |
| Предпросмотр архивированного | Щёлкните фрагмент совпадения или **Дополнительно → Быстрый предпросмотр** |
| Очистить неактивные чаты | На вкладке **Незаархивированные** задайте **Дни простоя**, просмотрите кандидатов и подтвердите |
| Найти сессию | Скопируйте её ID или путь через меню **Дополнительно** |
| Обработать ошибки чтения | Разверните диагностику, сначала продиагностируйте, затем подтвердите ремонт, если допустимо |
| Архивировать по проектам | Переключитесь на **Незаархивированные**, выберите сессии в разных проектах, затем нажмите **Архивировать** и подтвердите |
| Массовое восстановление или удаление | Выберите чаты и используйте массовые действия или меню проекта; отдельных кнопок «Восстановить всё» / «Удалить всё» нет |

Страница открывается на вкладке **Архив**, справа — **Незаархивированные**. Переключение вкладок сбрасывает выбор; смена поиска или фильтра проекта сохраняет его. Проверьте скрытое число выбранных перед массовым действием или сначала очистите выбор.

**Выбрать все результаты** выбирает подходящие сессии, включая свёрнутые группы. Действия по всему проекту по-прежнему применяются ко всему проекту независимо от фильтров поиска. Вкладка **Незаархивированные** исключает субагентов и пустые заглушки.

Массовое архивирование и восстановление из настроек и боковой панели последовательно вызывают официальные API `ctx.workspaces.archiveSession` и `ctx.workspaces.unarchiveSession`.

### Избранное и очистка неактивных

Компактные группы проектов можно сворачивать. Звёзды и значки восстановления/архива появляются справа; в меню архивированной сессии есть «Восстановить и открыть» и удаление.

- Используйте звезду на любой вкладке и выпадающий список **Только избранное**, чтобы найти важные чаты. Избранное сохраняется на хосте при архивировании, восстановлении и смене браузера. Переоткройте управление, чтобы увидеть изменения, сделанные на других страницах. Неизвестные или нечитаемые сессии сохраняют свои сохранённые ID избранного; очистка требует подтверждённого отсутствия артефакта.
- На вкладке **Незаархивированные** введите 1–36 500 целых дней в поле **Дни простоя** и просмотрите кандидатов при текущих фильтрах. Снимите отдельных кандидатов перед подтверждением. Избранное, текущий чат, запущенные сессии (включая субагентов) и ожидающие взаимодействия защищены; сессии без корректного времени активности исключаются.
- Архив повторно проверяет избранное и активность. Пакетное архивирование, восстановление и удаление показывают ход и число успешных, пропущенных и неудачных элементов. Ошибка одной записи не останавливает остальные; повтор затрагивает только неудачные. Повторное удаление всё равно требует подтверждения.
- **Отменить эту архивацию** восстанавливает сессии, архивированные текущим пакетом, включая успешные повторы. Доступно, пока открыта текущая страница управления; обновление или закрытие очищает его. Постоянное удаление отменить нельзя.
- Избранное всё ещё можно архивировать вручную. Защита относится только к очистке неактивных. Плановой или автоматической фоновой очистки нет.

### Просмотр и продолжение архивированных бесед

Нативная навигация по беседе доступна с `0.1.40`; в 1.0.0 используются такие точки входа:

- **Щёлкните название сессии**: откройте нативную сессию DSH для просмотра сообщений, вложений и деталей инструментов. Продолжайте общение, сохраняя сессию архивированной.
- **Дополнительно → Восстановить и открыть**: снимите архивирование с сессии и откройте её, чтобы продолжить работу.

## Совместимость поискового API (для интеграторов)

Канонический API — `workspaceRegistry.searchSessionContent({ sessionIds, query })`, покрывающий архивированные и незаархивированные сессии. Передайте 1–20 ID сессий и непустой запрос в 1–200 символов; ID дедуплицируются. Результат имеет вид `{ items: [{ sessionId, seq, snippet }], failures: [{ sessionId, message }] }`. Отдельные ошибки чтения попадают в `failures`; некорректный ввод отклоняет вызов.

`searchArchivedContent` остаётся устаревшей точкой входа только для архива. Обе используют существующее подключение Typert хоста и границу авторизации; никакого HTTP-эндпоинта или настройки аутентификации не добавляется. Сохраняйте устаревший дескриптор во всём поддерживаемом диапазоне хостов, включая патч-релизы. Удаление требует явного изменения диапазона совместимости, миграции клиента и уведомления об устаревании. Новые клиенты предпочитают канонический API и используют старый только как запасной вариант для версий, никогда не отправляя один и тот же поиск в оба.

## Обновления

Нажмите **Check for updates** в заголовке страницы управления архивом (кнопка пока на английском). Среды DSH CLI или Desktop с поддержкой автоматического обновления могут обновиться напрямую; другие среды дают ручную команду для текущего профиля. Можно также перевыполнить команду установки выше.

## Частые вопросы

### Почему записи нет после установки?

Перезапустите DSH Web и жёстко обновите браузер. Убедитесь, что установили в используемый профиль. Если записи всё ещё нет, выполните:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

dsh --profile web --dump-config
```

В конфигурации должен присутствовать `ui-workspace-archive-manager`, и он не должен отключать официальные `workspace` или `session-projection-cache`. Оставшийся override `archive-manager-host` можно удалить. В текущих хостах DSH официальной записи `ui-settings-unarchive-sessions` уже нет, поэтому плагин больше её не отключает (иначе dump-config предупреждает, что запись патча не найдена). Если `cordis.patch.yml` вашего профиля всё ещё отключает `workspace`, `session-projection-cache` или `ui-workspace`, удалите эти override и перезапустите.

### Сохраняются ли названия после отключения исправленной версии?

Исправленная версия больше не заменяет официальную таблицу кэша проекций. При включении она проверяет идентичность сессии и переносит совместимые старые записи плагина в официальный кэш, сохраняя исходные файлы. **Если старая версия была отключена, исправленную версию нужно включить хотя бы один раз для переноса**; замена пакета в отключённом состоянии не запускает миграцию.

Неудачный перенос можно повторить при следующем включении. Ключи, которые официальный backend не принимает (например, ID с двоеточием), остаются в старом домене плагина. Для этих сессий восстанавливается штатное поведение кэша хоста; журналы разговоров не удаляются. Подробности — в [журнале изменений](CHANGELOG.md).

### Чем архивирование отличается от удаления?

Архивирование убирает беседу, чтобы позже её можно было восстановить. **Постоянное удаление отменить нельзя** и оно может также удалить вложения этой сессии. Оно не удаляет рабочую директорию вашего проекта. Удаление требует подтверждения.

### Можно ли использовать с Codex UI?

Да. [Codex UI](https://github.com/MichengAI/dsh-codex-ui) сохраняет свой внешний вид и взаимодействие. Управление архивом остаётся доступным в **Настройки → Архив сессий**.

При других проблемах откройте [issue](https://github.com/MichengAI/dsh-archive-manager/issues) с версиями DSH и плагина, шагами воспроизведения и деталями ошибки.

## Установка из исходников

<details>
<summary>Развернуть для разработки или тестирования неопубликованных изменений</summary>

Выполните эти команды в каталоге по вашему выбору. Для локальных изменений, которые ещё не запушены, используйте существующую рабочую копию.

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8

git clone https://github.com/MichengAI/dsh-archive-manager.git
Set-Location .\dsh-archive-manager
pnpm install --frozen-lockfile
pnpm build
dsh plugin --profile web add .
```

После этого перезапустите DSH Web и жёстко обновите браузер. Исходный код в [src](src) использует строгий TypeScript. GitHub и npm включают готовый к запуску `lib`. После изменения исходников выполните `pnpm build` перед коммитом, иначе установка из исходников сохранит прежний рантайм. Опубликованные точки входа JavaScript и модули рантайма не меняются; установка npm-пакета не требует TypeScript. Выполните `pnpm typecheck` для проверки типов, `pnpm test` для проверки изменений или `pnpm verify` для полных проверок.

</details>
